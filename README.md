# PowerHop (edited by Ava)
An object-oriented program inspired by frogger with added powerups that give the player special advantages. There is a screen with 5 lanes of moving cars and then a river behind it with floating logs. Behind the river there are 5 chunks of land. The player has five frogs that they need to get to the landing spots without dying one at a time. While they do this the user should try to get the most points possible. The user can use the arrow keys or WASD to move the player across the screen. If the player lands in the river or gets hit by a car they die. The frog can ride on logs to help cross the river. At regular intevals both powerups and flies will appear which the user can collect by colliding with them. Collecting flies gives the user extra points. There are 3 types of powerups that the user can collect which give the following benefits: slow time, double points, and health bonus. The game ends when the user gets all the frogs to the goals or when they die.


To run the app click on the code icon in github, download the whole repository as a zip file, and then open main.pyde in processing.
